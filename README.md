One line, 77 characters: a robot that brute-forced politeness and still picked the worst greeting.

The joke turns on machine logic meeting social awkwardness: this robot ran 4,096 simulations of saying hello in an elevator, and the punchline is that all that compute still produced the most awkward option — the machine did everything right and the conversation is still a disaster.
